# Install

Install agents-sandbox, then check your system is ready.

- [Prerequisites]({% link install/prerequisites.md %})
- [Installation]({% link install/installation.md %})

> **New to coding agents?** Set up your agent (opencode, pi, or claude-code) on your host first
> using its normal setup. Then run `agents-sandbox`: if native configuration is detected, the interactive startup offers a
> safe migration into a clean, managed sandbox configuration before the VM starts. If you prefer to build the managed
> configuration from scratch, choose the manual configuration path in [Manage config in the sandbox]({% link manage-config.md %}).
