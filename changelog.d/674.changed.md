(`type=registry`), so the `main`-written cache is no longer evicted by the repository's 10 GB Actions cache
budget; `main` stays the single writer and every other run restores (#636). The cache-export permission
(`packages: write`) is confined to a separate main-push job, so a PR or dispatch run's saved GHCR credential is
read-only (#636).
