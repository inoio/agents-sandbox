Internal: the microsandbox adapter's creation interfaces now take launcher-owned value types
instead of SDK types — `CreateSandbox(name, SandboxSpec)` and `CreateVolume(name, VolumeSpec)`,
with the mount model (`MountConfig` + `Mount` factory), `PortBinding`, `SecretEntry`, and
`NetworkSpec`. `vm` project-VM creation, the `volume`/`runtimemigration` create paths, and the
`network`/`envsecret`/`ports`/`state` producers no longer import the SDK (#196).
