Internal: the host-only test tiers run faster. `test-integration`'s image-build subtests run in parallel
  (`INTEGRATION_PARALLEL`) and stop pruning the classic-builder parent images they reuse (`removeTestImage`), so a
  warm run no longer rebuilds every agent/docker layer. `test-msb` runs its harness subtests in parallel under a
  count sized to the host's free memory (each smoke VM boots at `--memory 2G` instead of 4 GiB, and the count divides
  free memory by a 1.5 GiB working-set estimate; `MSB_PARALLEL` overrides the count) with a bounded image-prebuild
  pool, and `make test-msb-reuse` (via
  `AGENTS_SANDBOX_SMOKE_ROOT` / `AGENTS_SANDBOX_MSB_TEST_HOME`) keeps the microsandbox home between runs so the
  multi-GB runner-image transfer is paid once; each harness also gets its own prepared HOME/TMPDIR tree. The
  docker-storage smoke is folded in as a sibling subtest of the harness smoke, and both it and oh-my-pi now ready on
  real signals (the shell's first echoed command; oh-my-pi's startup warning) instead of waiting out the 25s settle,
  which was the suite's floor. No behavior change (#596).
