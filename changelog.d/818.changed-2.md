Extract the shared `msb`-suite driving support into a new untagged `test/msb/driver` package: the harness table
(`Spec`/`Specs`) with its ready-marker and smoke-config constants, and the output helpers (`StripANSI`,
`TUIStarted`, `SawDaemonTimeout`, `UsableTerm`). Unlike the `msb`-tagged smoke package, the driver's unit tests run
in the default `make test`, so the harness-table completeness test now runs there.
