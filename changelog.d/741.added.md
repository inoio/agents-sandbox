Added the learn-mode findings engine (S6 of #697): `internal/sandbox/analyser` turns a finished session's home
read-back and observation capture into findings the user reviews and applies. It derives a network diff that never
widens a policy (the terminal `none` profile plus the current allow set unioned with the destinations the session
used), attributes a learned static secret to the hosts the channel saw it sent to or the endpoint its config entry
names, and skips a secret that cannot be attributed. The interactive per-finding applier writes each finding's
writes together, skips a per-slug key the project layer owns, remembers a decline by evidence hash in the user
state dir, and keeps its config writes YAML-only. It adds `envsecret.WriteSecretSpec`/`RemoveSecretSpec` and
`viperconfig.RemoveSetting` as the secret and config write primitives `config harden` reuses. The engine is a
library; `run --learn` that wires it is a later change.
