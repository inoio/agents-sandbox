CI: a change that touches only execution-inert paths (the operator brain, the dev VM, the Homebrew formula,
issue templates, root Markdown, `.gitignore`) still runs every required check but skips the whole-module work
(golangci-lint, `compile-all`, `validate-fmt`, `test`, `race`, `deadcode`), and an undecidable base or a failed
diff now fails closed and runs everything instead of silently skipping. Every CI job is bounded by a
`timeout-minutes`, the main-push build imports the GHCR build cache and re-exports only the changed layers, and
the cold uncached image build and the rootless-podman engine build moved to a nightly scheduled run so they no
longer cost every merge.
