`run --serve-only` now prints the stop key that actually works: `Press Ctrl-D to stop serving.` when an interactive stdin is watched for EOF, and `Press Ctrl-C to stop serving (stdin is not a terminal).` otherwise. Previously the message always said Ctrl-D, which only works on a terminal — with a piped or closed stdin (the `printf '' | agents-sandbox run --serve-only` form) only `SIGINT`/`SIGTERM` stop the run (#677).
