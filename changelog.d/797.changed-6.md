Add the scaffolding for the harness-journey acceptance suite (`test/msb/journeys`, `make test-msb-journeys`): a journey
model of named steps drawn from one shared vocabulary, an untagged coverage/exemption table whose completeness test runs
in the default `make test`, and an `msb`-tagged host runner that builds the launcher, prebuilds the runner images, and
drives each journey through a real microsandbox VM (#793). The post-exit-prompt wait gets its own larger bound
(`ExitSaveTimeout`) because answering "Save all" runs the analysis/save path before the process exits, and a
driver-closure contract test keeps the shared `test/msb/driver` import graph free of `testing` and test-support
packages.
