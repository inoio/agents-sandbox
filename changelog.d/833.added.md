Add the harness-journeys acceptance suite (`test/msb/journeys`, `make test-msb-journeys`): a second `msb`-tagged
suite that drives full user journeys through a real harness beyond first start, sharing the untagged
`test/msb/driver` package. v1 covers learn mode on opencode2 with UC1 (`run` → learn-by-using), UC4
(host-seed), the `config learn` replay, and the attribution journey, over a shared named-step vocabulary.
It ships a host-side stub provider: a loopback HTTP destination plus the opencode2 provider config that
points an agent at it through the terminating proxy, without real egress. The advertised origin is
overridable with `AGENTS_SANDBOX_JOURNEYS_STUB_ORIGIN`.
