State and config YAML now serializes through `go.yaml.in/yaml/v4`. The `yaml/v3` emitter wrote a value whose first
character is a tab as a block scalar it could not itself re-parse, so a hand-edited `state.yaml` the launcher accepted
could be rewritten into an unreadable one. v4 quotes such values and round-trips; viper keeps its own read-only
`go.yaml.in/yaml/v3`.
