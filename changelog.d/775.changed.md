`provision-host-config` now defaults to `false`: the launcher no longer copies the active agent's host config and
credentials into the VM unless you opt in with `provision-host-config: true`. Previously copied host config and
credentials — including a copied `auth.json` — are removed from existing sandboxes on the next run, since provisioning
is now off by default; opt in again with `provision-host-config: true` to keep the drop-in copy. An unconfigured first
run offers a guided path instead — learn by using it, learn from your host setup, or configure it myself (#98, #697).
