The KVM-guest provisioner now keeps its guest disk, seed, and domain XML under the libvirt images tree instead of the working directory, so worktrees no longer each grow a guest. The one shared guest is locked to the branch using it (running = held, paused/down = free); hand it to another branch with `make kvm-pause`. A guest created before this change keeps its old per-worktree disk; remove the leftover `$PWD/.kvm-guest/` by hand once (see `guides/kvm-guest.md`).
