Make the host the KVM guest's git remote: `make kvm-sync` now points the guest's `origin` at the host repository
through a `url.*.insteadOf` rewrite and pulls the host's branch over git (replacing the one-way, destructive rsync),
fast-forward only. The guest can push its branches straight to the host; `gh` stays signed in for issues and PRs, but
the guest no longer rewrites or pushes to GitHub.
