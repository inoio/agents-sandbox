Moved the remaining shell test harnesses into the Go `test/scripts` package: their cases now run through a shared git-isolation runner with go-git fixtures and re-exec fake commands, and the shared helpers live as `*_helpers_test.go` files. The `rebase-status` and `cleanup-merged-branches` harnesses are ported too, driving their real-git fixtures through one shared exec-git porcelain helper that applies the same host-git-config isolation, and the `ci/check-docs.sh` harness moved to Go — no bash test harness remains. `scripts/test-envelope.sh` was renamed `scripts/hermetic-envelope.sh`, and the surface-sweep relative-root test now sizes its socket root like the old bash harness did (macOS `/private/tmp`). Developer-only change.
