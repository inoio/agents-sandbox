The git-fixture shell test harnesses under `scripts/` move to a Go `test/scripts` package that drives the tools through `RunScript` with `gittest` go-git fixtures and re-exec fake commands. Host git config is neutralized by the shared helper instead of a hand-copied head, so a signing `commit.gpgsign` no longer makes the harnesses prompt for a passphrase: `open-backport-pr`, `backport-audit`, `changed-files`, and `changed-targets` are migrated. The shared helpers (`RunScript`, the `gittest` fixture builder, `fakecmd`) live in the package as `*_helpers_test.go`, so coverage and `deadcode` skip them by name — no `.codecov.yml` ignore or `//deadcode:ignore` marker. The backport-audit harness's fake `gh` fails any request naming a `commits` field, pinning that the audit reads a PR's commits from the local clone rather than the API.
