The git-fixture shell test harnesses under `scripts/` move to a Go `test/scripts` package that drives the tools through `testutil.RunScript` with `gittest` go-git fixtures and re-exec fake commands. Host git config is neutralized by the shared helper instead of a hand-copied head, so a signing `commit.gpgsign` no longer makes the harnesses prompt for a passphrase: `open-backport-pr`, `backport-audit`, `changed-files`, and `changed-targets` are migrated.
