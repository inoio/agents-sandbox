Internal: the microsandbox adapter's role interfaces now return launcher-owned value types and enums
instead of SDK types — `StorageReport`/`StorageCategory`/`StorageItem`/`PruneRequest`/`PruneReport`,
`JobInfo`/`JobLogEntry`/`JobLogQuery`/`LogEntry`/`Metrics`,
`ImageConfig`/`ImageLayer`/`ImagePruneReport`, and the string-backed
`SandboxStatus`/`BackendKind`/`VolumeKind`. `storage`, `pressure`, `resourceproposal`, `image` and
`session` no longer import the SDK at all, pinned by a package-boundary test (#196).
