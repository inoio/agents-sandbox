The `--notify <mode>` and `--open-links <bool>` space forms are now parsed as flags on `run` instead of being
 forwarded to the agent: previously the documented form silently did the opposite (the notify watcher stayed
 active) and the bare word (`off`, `false`) leaked into the agent's arguments. The following token is taken as
 the flag's value only when it reads as one -- a notify mode (`on`/`off`/`desktop`/`audio`, case-insensitively)
 or a boolean literal -- so that value is validated exactly like the `=` form and `--notify OFF` or
 `--open-links off` is still rejected. A plain word (`--notify fix the bug`) stays a positional argument and is
 forwarded to the agent, as non-flag arguments before `--` always were.
