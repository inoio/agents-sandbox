Runner image: the launcher now builds the runner image with BuildKit when the engine advertises an
  embedded builder, or with the classic builder when the engine advertises only that, and honors two
  build-cache keys (`image-cache-from`/`image-cache-to`) so a build can import from and export to a
  cache backend. CI's
  `integration` docker-build job is now a required check that runs on every code-affecting pull
  request and restores from a shared GitHub Actions cache that only a push to `main` writes, so PRs
  get cached builds without ever publishing a merge-ref cache. A `type=gha` cache entry takes its
  cache-service url and token from the `ACTIONS_*` environment (the CI exposes them with
  `crazy-max/ghaction-github-runtime`), since the engine's BuildKit cannot read the step's environment
  (#597).
