`make check` is concise: a new `scripts/check.sh` runner runs each target as its own `make` call with output
captured, prints one `PASS`/`FAIL <target> <n>s` line per target, and dumps the captured log of every failing
target last, replacing the ~800 lines of per-case output. The CPU-heavy targets (`validate-fmt lint test
compile-all`) run one at a time and the rest in a `JOBS=<n>` pool, so a check run no longer oversubscribes the
box. `VERBOSE=1` streams each target's output and `SERIAL=1` runs one target at a time. The fixture harnesses
print their per-case lines only on failure or `VERBOSE=1`. `make check-local-changes`/`check-branch-changes`
use the same runner, and `scripts/changed-targets.sh` now reads the full target set from make's new
`print-check-targets` instead of grepping the Makefile.
