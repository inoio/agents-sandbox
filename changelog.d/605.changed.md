Document the launcher's cross-layer dependency edges (#532). The run-options aggregate no longer imports the
state package: the project-VM lock seam takes a leaf `options.ProjectVMKey` that `vm` adapts to `state.Key`.
The two remaining edges, `viperconfig` reading the sandbox mount/network value packages and `notify` using the
state and msb seams `session` injects, are now recorded as deliberate exceptions.
