The `network:` block now exposes microsandbox's TLS-interception controls. `network.intercept-tls` (`auto`, `on`, `off`)
selects interception; `network.tls-bypass` lists hosts that are not intercepted; and `network.disable-strict` turns off
the runtime's strict-hostname mode so a bypassed-and-allowlisted host is reachable. All three are creation-only and part
of the network fingerprint. A new recipe, `docs/recipes/docker-ca-trust.md`, explains how to make an in-VM `docker
build` or `docker run` container trust the interception CA.
