Extract the pty session into the untagged `test/msb/driver` package: the `Session` type and `StartUnderPTY`/
`MustStartUnderPTY` constructors, the readiness and exit helpers (`Output`, `Write`, `WaitForTUI`, `WaitSettled`,
`WaitForMarker`, `WaitExit`, `HasExited`, `Close`, `DrainOutput`, `ExitStatus`, `OutputTail`), and the supporting
`MarkerText`, `TerminalSize`, `TerminalDimension`, `KillProcessGroup`, `KillProcessGroupWith`, `ExitErrorCode`,
`ExitCode`, `TuiLeft`, and `TeardownStarted`. The platform termios constants move to non-test driver files so the
untagged session compiles, and the driver's pty unit tests run in the default `make test`.
