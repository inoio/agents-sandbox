The CI `integration` docker-build job now reports the engine's streamed build log when an image build
  fails, so a failing install step (for example pi's `npm install`) surfaces the step's own error output
  instead of only the terse solve message. The job's `crazy-max/ghaction-github-runtime` step is updated
  to `v4`. The `integration` podman-build job now runs its suite serially (`INTEGRATION_PARALLEL=1`, with
  a raised `INTEGRATION_TIMEOUT`), avoiding buildah's parallel-build cache race that corrupted its layer
  store (`layer not known`).
