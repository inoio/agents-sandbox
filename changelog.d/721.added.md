The `network:` block now configures a first-class outbound egress proxy for the sandbox. `network.proxy.protocol` and
`network.proxy.address` select the proxy — `http-connect`, `socks5`, or `socks4` — and `network.proxy.username` with
`network.proxy.password-env` carry the proxy credentials for HTTP CONNECT and SOCKS5 (SOCKS4 takes none). The
`--proxy protocol://host:port` flag overrides the block for one run. The runtime dials the proxy on the host, so the
proxy address needs no `egress-allow` entry, and the proxy is part of the network fingerprint: a change recreates the
VM.
