GitHub release lookups for unpinned agent builds now authenticate with a `GH_TOKEN` or `GITHUB_TOKEN`
from the environment when one is set, so resolving the latest agent version is no longer subject to
the anonymous GitHub API rate limit. A token GitHub rejects is retried once without it, so an expired
or under-scoped token falls back to the anonymous lookup instead of failing the build. The token is
sent only to `api.github.com`.
