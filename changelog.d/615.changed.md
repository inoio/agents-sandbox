Internal: the microsandbox adapter's read-back interfaces now take and return launcher-owned value
types — `SandboxConfigReader.Config`/`ConfigMounts`/`ConfigPorts` return `SandboxConfig`,
`MountConfig`, and `PortBinding`, and `SandboxResourceControl.Modify`/`Compact` take `ModifyOptions`
and return `SandboxModificationPlan`/`DiskCompactionResult`. With the SDK now an implementation detail
of `internal/sandbox/msb` alone (residue: `internal/sandbox/runtime`), the launcher no longer imports
the microsandbox SDK outside the adapter (#196).
