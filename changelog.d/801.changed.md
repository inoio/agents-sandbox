Made the hermetic suite's host figures deterministic: the launcher's installed-RAM, CPU-count, and
host-available-memory reads now go through one seam (`internal/hostfigures`), shared by `vm`, `prepare`,
and `session`, and pinnable by a test binary. The envelope targets (`make test-scrubbed`, `test-hermetic`,
and the new `test-hermetic-sentinel`) run a sentinel pass (`--sentinel`) that pins the seams to non-host
sentinels, so a default-suite test that still reads the real host figures fails; every `TestMain` that
installs the fail-fast mocks installs the sentinel too, and the ambient gate now flags a direct read of a
seam accessor as well as a raw `sysinfo` read. The two `cmd` tests that assumed the host RAM were pinned,
and `sysinfo`'s and the leaf's `TestMain` moved to external test packages. Developer-only change (#801).
