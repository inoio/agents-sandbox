Made the hermetic suite's host figures deterministic: the launcher's installed-RAM, CPU-count, and
host-available-memory reads now go through one seam (`internal/hostfigures`), shared by `vm` and
`prepare` (as `session`'s already were) and pinnable by a test binary. `make test-hermetic` gains a
second sentinel pass (`--sentinel`) that pins the seams to non-host sentinels, so a default-suite test
that still reads the real host figures fails; the two `cmd` tests and `sysinfo`'s `TestMain` that
depended on the host were updated. Developer-only change (#801).
