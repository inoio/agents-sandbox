A first run now offers three choices before the agent starts — **Learn by using it**, **Learn from my host setup** (only
when host config exists), and **Configure it myself** — so a fresh install reaches a working sandbox without declaring
providers and hosts up front. Either learning choice starts a learning session; the host-seeded one copies your host
config as placeholders, never raw credentials. **Configure it myself** carries the `provision-host-config: true` opt-in
warning, and the decision is recorded so later runs stay quiet until the host config changes (#54, #697).
