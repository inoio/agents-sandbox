Added the learn-mode observation channel (S4 of #697): a launcher-owned `elazarl/goproxy` terminating proxy
(`internal/sandbox/channel`) that records which destinations a sandbox session used and which
credential-bearing header **names** it carried (names only, never values or bodies), plus an in-memory
network overlay the run applies at VM creation. It adds a `TLSConfig.UpstreamCACerts` projection so the
runtime trusts the proxy's per-session CA as an upstream CA (topology T2, no guest modification) and
persists the scrubbed artefact under the user state dir. The channel is a library; `run --learn` that wires
it is a later change.
