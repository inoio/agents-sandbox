Reconfiguring the project VM now shows what changed. With no other client attached the change is announced as a
warning instead of an info line, and both the warning and the keep/quit prompt list each change: mount sources,
network entries, published ports, the hosts a secret is sent to, environment variable names, changed agent config
files, and old → new image and home volume. Environment and secret values are never shown. A sandbox created by an
earlier version shows `(previous value not recorded)` on its first change (#230).
