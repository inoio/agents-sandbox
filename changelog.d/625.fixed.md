Internal: `make test-msb-reuse` no longer deadlocks. A reused microsandbox home
  (`AGENTS_SANDBOX_MSB_TEST_HOME`) is held under an exclusive lock for the whole run, and the real-client lifecycle
  test's child processes inherited that variable, so each child's `TestMain` blocked on the lock the parent already
  held while the parent waited on the child's ready line. The child is now spawned without the variable
  (`runtime.WithoutReuseHome`), so it borrows the parent's home without re-entering the lock.
