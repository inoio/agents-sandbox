`run --serve-only` on a kept VM whose serve binding can only change on recreate now exits cleanly after warning that the agent server is unreachable, instead of taking a client lease, starting a VM keeper, and blocking. The deferred run held the VM past its idle timeout and its lease made the last-client reap a no-op, so the warning's own remedy — stop the attached clients and re-run to recreate the VM — could never be followed (#677).
