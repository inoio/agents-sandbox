VM size settings are now validated as a contract: `memory` has a 128 MiB floor, `tmp-size` defaults to
  `min(2 GiB, memory/2)` and must be less than `memory` (a host-RAM clamp keeps the two in order at boot),
  and `disk-size`/`workspace-quota` must be positive — a zero, non-positive, or
  not-smaller-than-memory value is rejected with an error naming the key (#606). The `/tmp` raise offered after a
  full-disk detection is kept strictly below the memory limit, so an accepted raise stays valid.
