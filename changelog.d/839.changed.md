Settings an agent saves in its own main config inside the sandbox — a model chosen with `/model`, codex's folder trust, goose's telemetry answer — now survive the next run and a second attach. agents-sandbox owns only the keys it writes from your snippets or the drop-in copy: it sets those again on every run and leaves the agent's other keys alone instead of resetting or removing the file, and an agent's own write no longer triggers the reconfig prompt.
