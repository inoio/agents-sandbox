Config-file reading is unified on one `internal/configdecode` core shared by the launcher, the home manifest, and the
agent-snippet loaders, so a file one loader accepts cannot be rejected — or parsed differently — by another. As a
consequence a `.json` config now also accepts `//` comments and trailing commas, and the launcher config is parsed
with the same `go.yaml.in/yaml/v4` parser the launcher writes with (#531).
