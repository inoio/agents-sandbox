Codex no longer warns about embedded mode on every start or asks whether to trust `/workspace` on every run (#807).
The image now sets the launcher's codex defaults (update check off, `sandbox_mode = "danger-full-access"`,
`/workspace` trusted) in `/etc/codex/config.toml`, codex's lowest config layer, instead of passing `-c` overrides,
and codex runs with `--no-daemon`. Every other codex config layer now overrides these defaults: your codex
`config.toml` (snippet or host drop-in), a repository's `.codex/config.toml`, and a `default_permissions` profile. A
trusted `/workspace` loads the repository's `.codex/` config, hooks, and MCP servers without asking. Codex must be
0.156.0 or later (an `--agent-version` pin or a custom base's codex), and a forwarded `--remote` is rejected.
