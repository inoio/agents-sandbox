Codex no longer warns about embedded mode on every start or asks whether to trust `/workspace` on every run (#807).
The image now sets the launcher's codex defaults (update check off, `sandbox_mode = "danger-full-access"`,
`/workspace` trusted) in `/etc/codex/config.toml`, codex's lowest config layer, instead of passing `-c` overrides,
and codex runs with `--no-daemon`. A `sandbox_mode` in your codex `config.toml` now takes precedence over the
launcher's default, and `--agent-version` must name codex 0.156.0 or later.
