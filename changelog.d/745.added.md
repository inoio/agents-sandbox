Added learn mode: `agents-sandbox run --learn` observes a session through a host-owned proxy, reads the sandbox
home back, and proposes the per-slug user config the session actually needed — a narrowed `network.egress-allow` set
and the static secrets it could attribute to a destination — behind a Review and save / Save all / Not now prompt.
`agents-sandbox config learn` replays the analysis for a session whose owning process is gone, and an unreviewed
capture is swept after 30 days (#697).
