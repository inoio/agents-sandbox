Runtime setup calls name the home explicitly via `RuntimeConfig.Home` (`configpaths.MSBHome()`), making resolution order-independent while `MSB_HOME` stays the FFI/other-op home (issue #160). A one-time, acknowledged post-migration notice (design finalized 2026-10-16, not yet implemented) tells upgraders their system-wide microsandbox is now optional: file-based detection (our `agents-sandbox-home-*` volumes / launcher-prefixed sandbox records), fires on completed/dismissed/already-terminal-with-leftovers/pending-nothing-to-copy, warns on excluded volumes, instruct-only (never deletes), tracked by a second `migrations` registry entry, with a new `termio` acknowledge primitive.
